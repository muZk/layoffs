# Cobertura y revisiones

Snapshots de cobertura, conciliación y cambios antes/después que respaldan la base curada. Son evidencia de procedencia y auditoría, no resultados exploratorios independientes.

El snapshot general es del 17 de septiembre de 2026; las revisiones llegan al 29 de septiembre. `scripts/validate_causes.py` aplica la cadena de cambios para comprobar el JSON actual. Los recuentos históricos presentes en cada revisión corresponden a ese momento, no necesariamente al estado vigente.
