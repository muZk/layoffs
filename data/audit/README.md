# Auditoría de clasificaciones

Estos archivos son antecedentes históricos necesarios para `scripts/validate_causes.py`; no describen por sí solos la clasificación vigente.

La reconstrucción parte de las revisiones iniciales conservadas aquí y aplica secuencialmente las incorporaciones y revisiones de `coverage/`. El resultado debe coincidir exactamente con `2026-categorized.json`. Por eso se conservan estos antecedentes aunque se retiren análisis exploratorios antiguos, cachés y artículos.

Consultar el JSON canónico para el estado actual; no contar eventos a partir de estos archivos, porque contienen estados anteriores y posteriores del mismo registro.
